# OMIYAcappella — Website Prototype

大宮アカペラプラットフォーム **OMIYAcappella**（[@OMIYAacappella](https://x.com/OMIYAacappella)）の
Webサイト・プロトタイプです。運営メンバーへの提示用で、まだ本番公開はしていません。

> **Status: プロトタイプ**
> 画面右下に `PROTOTYPE` バッジを表示しています。本番公開時は `.proto-flag` を削除してください。

---

## 構成

```
.
├── index.html          # トップページ
│     01 About     — コンセプト／参加のながれ／募集要項／FAQ／活動ルール要約
│     02 Gallery   — 演奏動画・写真（絞り込み＋ライトボックス）
│     03 Projects  — 企画募集（LINEグループ由来のタイムライン）
│     04 X         — 投稿の埋め込み＋ライブタイムライン
│     05 Contact   — 連絡フォーム
├── rules.html          # 活動ルール全文（Aboutの「活動ルールを詳しく見る」からリンク）
├── assets/
│   ├── css/style.css   # 全スタイル（デザイントークン → セクション順）
│   ├── js/main.js      # ローダー・ナビ・スクロール演出・ギャラリー・フォーム（依存なし）
│   └── img/            # 画像一式
└── .claude/launch.json # ローカルプレビュー用の簡易サーバ設定
```

素の HTML / CSS / JavaScript のみで、ビルド不要です。

## ローカルで見る

```bash
python3 -m http.server 4321
```

その後ブラウザで <http://localhost:4321> を開きます。
（`file://` で直接開くと相対パスとX埋め込みが解決されないため、簡易サーバ経由を推奨します）

## デザイン方針

- ロゴ・Xバナーの配色（黄 / サーモン / ティール / グリーンの4円 ＋「大宮」のオレンジ）を
  そのままデザイントークンに落とし込み、サイト全体の色をブランドと一致させています。
- 参考にいただいた採用サイトに倣い、**セクション番号（01〜05）＋大きな見出し＋広い余白**の
  縦積みレイアウト、背景に薄いゴースト数字、区切りの幾何学モチーフ（ひし形）を採用。
- スクロール連動のフェードイン、ヘッダーの追従、ナビのスクロール・スパイを実装。
- `prefers-reduced-motion` に対応（アニメーションを無効化）。
- ブレークポイントは 1024px / 860px / 620px。860px 以下でハンバーガーメニューに切り替わります。

## セクション別のメモ

### 02 Gallery

- 「すべて／動画・音源／写真」で絞り込み。写真はライトボックス（← → / Esc 対応）、
  動画カードはXの投稿ページを開きます。
- ページ下部には X の投稿埋め込みを置いてあり、通信できる環境では**動画がその場で再生**されます。
- **現在の掲載点数は5件です。** ログインなしで参照できる X のプロフィールでは、
  188件の投稿のうち5件しか取得できないためです。
  演奏動画・音源のファイル、または投稿URLの一覧をいただければ随時追加します。
  音源（mp3など）を追加する場合は `assets/audio/` を作り、カードに `<audio controls>` を差し込む構成を想定しています。

### 03 Projects（企画募集）

- LINEグループのトーク履歴・ノートを想定した**サンプルデータ**で表示しています。
  セクション冒頭にもその旨を明記しています。
- 実データへの差し替えは `index.html` の `<article class="line-post">` を増減するだけです。
  1件あたり以下を持ちます。

  | 項目 | クラス／要素 | 備考 |
  | --- | --- | --- |
  | 日付 | `.line-post__date` | |
  | 種別 | `.tag--kind` / `.tag--note` | 企画募集・イベント・交流・ノート |
  | 状態 | `.tag--open` / `.tag--filled` / `.tag--done` | 募集中・成立・終了 |
  | 曲名／アーティスト | `.line-post__song` | |
  | 本文 | `.line-post__body` | 改行はそのまま反映されます |
  | 募集パート・練習場所など | `.line-post__foot` | |

- **投稿者名と楽譜URLは伏せる仕様**です。`<span class="masked">非公開</span>`
  `<span class="masked">グループ内で共有</span>` を使ってください（斜線ハッチで表示されます）。
  実データを流し込む際も、この2項目は必ずマスクしたままにしてください。

### 05 Contact

- ページ上にメールアドレスは表示していません。送信先は
  `assets/js/main.js` 冒頭の `FORM_ENDPOINT` で管理しています。
- 現在は [FormSubmit](https://formsubmit.co/) 経由で `REDACTED@example.com` に届く設定です。
  **最初の1回だけ、そのアドレス宛に FormSubmit から確認メールが届きます。**
  本文のリンクをクリックして有効化するまで、以降のメールは配信されません。
- 有効化すると `https://formsubmit.co/ajax/el/xxxxxxx` という別名エンドポイントが発行されます。
  これを `FORM_ENDPOINT` に差し替えると、**ソースコードからもアドレスが消えます**（推奨）。
- Formspree / Google Apps Script / サーバーレス関数など、POSTを受け付ける他のサービスでも
  そのまま動きます。`FORM_ENDPOINT = ''` にすると送信せず確認メッセージのみ返すモードになります。
- スパム対策として honeypot（`_honey`）を仕込んであります。
